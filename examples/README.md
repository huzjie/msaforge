# Examples

每个示例可直接 `python examples/<name>.py` 运行（脚本头部自动把项目根加入 sys.path）。

| 示例 | 内容 |
|---|---|
| `select_blocks_demo.py` | 展示 index 分支选块 + 召回 |
| `sparse_attention_demo.py` | 展示 sparse vs full attention 的输出 |
| `train_demo.py` | 训练 index 分支，看 skill/召回爬升 |
| `bench_demo.py` | 跑完整基准 |
| `serve_demo.py` | 起 HTTP 服务做端到端冒烟 |
| `multimodal_demo.py` | 原生多模态融合 + 3D attention |
